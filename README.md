# school_21_projects
Проекты, выполненные в рамках обучения в "Школе 21"

**Префиксы задач**

HCO - Haircut and Cosmetics Online. Система онлайн-записи для барбершопа.

FDO - Food Delivery Online. Система доставки продуктовых заказов.

DELO - Delivery. Сбор требований для системы доставки продуктовых заказов - техники V&S и brainstorming.

**Содержание**

Для каждой задачи:

ex00 - диаграммы потоков данных (data flow diagram)

ex01 - диаграммы плавательных дорожек (swimlane diagram)

ex02 - диаграммы плавательных дорожек, дополненные артефактами 

ex03 - диаграммы состояний (state diagram)

ex04 - таблицы состояний (state table)

**Отдельные документы**

ex01_DELO_brainstorming - сбор требований для системы доставки продуктовых заказов - техника brainstorming.

ex03_DELO_vision - сбор требований для системы доставки продуктовых заказов - техника V&S.

ex01_HCO_us_guest - user story для незарегистрированного пользователя ( посетителя ) барбершопа.

ex02_HCO_UC - use case "Выбрать услугу мастера и забронировать слот" - для барбершопа.
